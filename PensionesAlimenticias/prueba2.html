Registro de Alta

Movimiento seleccionado: Alta

Seleccionar tipo de movimiento

Elija el movimiento que desea registrar. El formulario aplica para Alta de pensión alimenticia o juicio mercantil.

1. Datos del oficio

Información del oficio recibido del Juzgado para el movimiento de Alta. Aquí se define si el trámite es pensión alimenticia o juicio mercantil.

Subir escaneo del oficio en PDF o imagen.

2. Datos del beneficiario

Información de la persona que recibirá la pensión (o del abogado en caso de juicio mercantil) para el movimiento de Alta.

Si el descuento es por porcentaje, capturar aquí.

3. Datos del trabajador

Datos del trabajador en nómina sobre el cual se aplicará el descuento en el movimiento de Alta.

Puedes seleccionar uno o varios tipos de sostenimiento.
El sistema obtiene percepciones, deducciones de ley y calcula el monto de descuento.

3.5. Cálculo específico: Juicio Mercantil

Este cálculo aplica únicamente si el Tipo de trámite es Juicio Mercantil. Fórmula: (Total de Percepciones – Descuentos de ley – Salario Mínimo) × 30%.

(Percepciones – Descuentos de ley – SM) × 30%
Total de adeudo / Cantidad por quincena.

4. Registro en SIAPSEP

Primero se verifica si el trabajador ya cuenta con registro en SIAPSEP. Si no existe, se capturan los datos para un nuevo registro. Este paso se ajusta al movimiento de Alta, Cambio, Baja o Reintegro.

Para pensión: Forma P o C. Para Juicio Mercantil: Forma M.

Si el trabajador no tiene registro previo, capture los datos base para darlo de alta en SIAPSEP.
